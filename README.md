# TestGen

Дәріс файлынан AI арқылы тест жасайтын сайт. Google Forms сияқты жұмыс істейді: мұғалім файл жүктейді, тест жасалады, мұғалім студенттерге сілтеме жібереді, студенттер тіркелмей-ақ тест тапсырады.

## Мүмкіндіктері

| Критерий | Сайтта қалай жасалған |
|---|---|
| Қарапайым интерфейс | 3 қадам: файл жүктеу → «Сұрақ жасау» → сілтемені көшіру. Тілдері: KZ / RU / EN, телефонға бейімделген |
| Тест түрлері | Бір жауапты таңдау, жазбаша жауап, сәйкестендіру. Нақты бөлінеді: 10 → 4+3+3, 15 → 8+4+3, 20 → 11+5+4, 25 → 14+6+5. Студентке бөлім-бөлімімен шығады, сұрақтар қайталанбайды |
| Баға қою | Балл, пайыз, әріптік баға (A…F), GPA, дәстүрлі баға. Сәйкестендіру сұрағына жартылай балл беріледі |
| Нәтижелерді сақтау | Әр жауап базада сақталады. Мұғалім кесте мен графиктерді көреді, Excel-ге жүктей алады |
| Университет жүйесімен интеграция | Сұрақтарды **Moodle XML** және **Platonus (.txt)** форматына экспорттау |
| Қосымшаны тестілеу | `tests/` папкасында 27 автоматты тест (pytest), GitHub-қа push жасаған сайын іске қосылады |

Тағы басқа мүмкіндіктер:
- мұғалім аккаунты (әр мұғалім тек өз тесттерін көреді);
- AI жасаған сұрақты өзгертуге немесе жоюға болады;
- уақыт шегі (таймер біткенде жауаптар автоматты түрде жіберіледі);
- сұрақтар мен жауап нұсқаларын араластыру;
- әр студентке барлық сұрақтың ішінен N сұрақ кездейсоқ берілуі;
- тестті жабу/ашу;
- дұрыс жауаптарды көрсету немесе жасыру;
- студент бетті жаңартып жіберсе де, жауаптары өшпейді.
- әр сұраққа уақыт (әдепкі 40 секунд): сұрақтар бір-бірден шығады, артқа қайтуға болмайды;
- көшіруден қорғау: студент басқа бетке немесе қосымшаға өтсе, тест 0 баллмен аяқталады және 15 минутқа бұғатталады (мұғалім баптауда өшіре алады).

## Жергілікті іске қосу

```bash
cd ~/testgen
python3 -m venv venv
source venv/bin/activate          # fish үшін: source venv/bin/activate.fish
pip install -r requirements-dev.txt
cp .env.example .env              # .env ішіне GEMINI_API_KEY жаз
uvicorn backend.main:app --reload --port 8000
```

Сосын браузерде http://localhost:8000 ашып, тіркел.

Gemini кілтін тегін алуға болады: https://aistudio.google.com/apikey

Тесттерді іске қосу:

```bash
pytest -q
```

## Тегін серверге шығару (Render + Neon)

Render-дің тегін тарифінде диск әр қайта қосылғанда тазаланады. Сондықтан деректер сыртқы тегін PostgreSQL базасында (Neon) сақталады.

1. **База.** https://neon.tech сайтында GitHub арқылы тіркел → **Create project** → **Connection string** көшір (`postgresql://...` деп басталады).
2. **Код.** Өзгерістерді GitHub-қа push жаса.
3. **Сервер.** https://render.com сайтында GitHub арқылы кір → **New → Blueprint** → `testgen` репозиторийін таңда.
4. Render екі мән сұрайды:
   - `GEMINI_API_KEY` — Gemini кілті,
   - `DATABASE_URL` — Neon-нан көшірген сілтеме.
5. **Apply** бас. 2–3 минуттан кейін сайт `https://testgen-xxxx.onrender.com` мекенжайында ашылады.

> Тегін тарифте сервер 15 минут ешкім кірмесе ұйықтап қалады. Одан кейінгі алғашқы ашылу шамамен 1 минутқа созылады. Сабақ алдында сайтты бір рет ашып қойсаң, студенттер күтпейді.
> Бір топ немесе бірнеше топ студенттің (50–100 адам) бір мезгілде тест тапсыруына жетеді. AI тек мұғалім сұрақ жасағанда ғана қолданылады, сондықтан Gemini тегін лимиті студенттерге әсер етпейді.

## Құрылымы

```
testgen/
├── backend/
│   ├── main.py      # FastAPI: API және беттер
│   ├── db.py        # SQLite (жергілікті) / PostgreSQL (сервер)
│   ├── auth.py      # мұғалім аккаунттары, сессиялар
│   ├── ai.py        # Gemini арқылы сұрақ жасау және тексеру
│   ├── parser.py    # .docx/.pdf/.txt оқу, тақырыптарға бөлу
│   ├── scoring.py   # жауапты тексеру және әріптік баға
│   └── export.py    # Moodle XML, Platonus, Excel
├── frontend/
│   ├── index.html, app.js   # мұғалім беті
│   ├── take.html, take.js   # студент беті (/t/<код>)
│   ├── i18n.js              # KZ/RU/EN аудармалар
│   └── style.css
└── tests/           # pytest тесттері
```
